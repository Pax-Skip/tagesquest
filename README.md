# Tagesquest

Private Tagesablauf-App als Spiel (XP, Level, Streaks) für den iPhone-Home-Bildschirm.
Reine Web-App (PWA) ohne Build-Schritt. Alle Daten bleiben lokal im Browser des Handys.

- `schedule.js`: Tagesplan, Trainingspläne A/B (hier Zeiten und Übungen ändern)
- `app.js`: Spiel-Logik und Oberfläche
- Lokal testen: `python -m http.server 5173`, dann http://localhost:5173

Aufs iPhone: Seite in Safari öffnen, Teilen, "Zum Home-Bildschirm".
